# Atlas 视觉与交互验收

验收日期：2026-11-03。本轮不提交、不推送、不部署；线上仍是此前发布版本。

## 范围

- Atlas 大模型能力地图品牌、深色科技首页、浅色阅读内页，以及可切换的深色阅读主题。
- 全站导航、侧栏、文章元信息、目录筛选、代码、表格、学习路径与移动布局统一。
- 五个可操作教学图解：Transformer、Attention、KV Cache、RAG、Agent。图解使用构造数据，不宣称真实模型或业务运行。
- 七个学习路径页面提供阶段选择与实践产出；不把浏览或点击伪装为能力认证。
- 保留上一轮四篇正文升级，以及既有 URL 与历史章节锚点。

## 验证结果

- 内容检查：233 篇知识文章、244 个目录页面。构建输出 264 个 Markdown 页面、265 个 HTML 页面；内部链接与锚点校验通过，原有 255 个 URL 保留。
- RAG、Agent 的 232 个历史章节锚点验证通过。
- 桌面 1440px 与移动 390px 检查覆盖首页、路径、目录、Transformer、Attention、KV Cache、RAG、Agent。
- 浏览器实测知识节点选择及跳转、路径切换、目录搜索/空结果/复位、播放/暂停/复位、减少动画和手动步骤。
- Attention：因果掩码下未来权重为零，取消后非零；softmax 权重总和约 100%。KV Cache：2048 输入、8 KV heads 为 0.2500 GiB；32 heads 为 1.0000 GiB，追加一个位置为 1.0005 GiB。
- RAG：初始无候选，召回阶段两份；关闭旧政策后仅一份且无旧金额。Agent：超时显示结果未知，再按稳定操作 ID 查询已有结果，不重复创建。
- axe-core 4.12.1：上述八类页面两种宽度均未报告自动检测违规；深色 KV 页面补查也未报告违规。部分颜色对比度及首页 ARIA 项返回 incomplete，因此不声明完整 WCAG 合规。
- 独立代码审查指出的控件焦点轮廓、旧 RAG 候选未真正移除两项问题已修复并浏览器确认。
- npm run check、npm run build 与 git diff --check 通过。

## 边界

- 教学动画只覆盖五篇代表文章，统一排版覆盖所有页面；其余正文并非全部重新技术审校。
- 未调用付费图片 API，未保存用户密钥；视觉由本地 SVG、Vue 与 CSS 实现。
- 保留既有依赖；已知 npm audit 告警与搜索资源体积告警不在本轮修复范围，没有杜撰 Lighthouse 分数。
- 预览截图保存在仓库外，仅作为实际视觉验收材料。
