# 2026-11-03 首轮升级设计与实施计划

本方案已经用户确认：全站分层与导航升级＋核心文章逐篇补强；L1/L2 为主线；保留品牌绿，采用技术出版物＋工程手册视觉。

首页由阅读主张、岗位路线、精选阅读、知识索引和学习入口组成，不堆砌装饰卡片。文章页统一信息栏，清楚区分主阅读级别、推荐岗位、估算时长、人工分级状态与仓库修改时间。完整目录支持级别与岗位筛选；路径选择器用目标、基础、时间三问推荐链接，不承诺就业结果。

## 实施与验收

1. 生成 `audit/inventory.csv`、`audit/report.md` 和 `docs/_data/pages.json`；排除 `docs/superpowers` 设计文档，不计入知识文章统计，URL 仍保留。
2. 所有知识文章补齐元数据；自动推断公开标记，不用自动分数充当内容质量。新增路径与目录页；导航数据共享同一目录。
3. 原生 Vue / VitePress slots 实现首页、筛选目录、三问入口与文章信息栏；保持本地搜索、主题切换、编辑链接。
4. 五篇核心文章补充决策表、失败案例、分层追问与一手参考；修正显存单位、等价性和复杂度边界。
5. 严格构建、链接与元数据检查接入现有部署工作流；桌面和移动端检查，批量修复后确认。

本轮不是全部正文的完整技术审校；机械统计不生成五维伪评分。自动标签属于初次分类，未逐篇人工核实。依赖安全告警单独报告，不借机升级全部工具链。
