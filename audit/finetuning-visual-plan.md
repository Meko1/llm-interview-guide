# 微调内容视觉补强

2026-11-03。延续用户已确认的 Atlas 能力地图、深色图解与浅色阅读方向；本轮仅扩展 LoRA 与 RLHF 两篇，不改变品牌，不提交或发布。

## 方案选择

- 装饰性动画：吸引注意但不解释机制，舍弃。
- 完整训练模拟器：成本与准确性风险高，不符合静态知识站边界，舍弃。
- 复用 LessonLab 控件的可复算图解：小体积、可暂停、键盘可操作，采用。

## 交互与动效

- LoRA：选择 rank、输出维度、alpha；按冻结、分支、前向、训练、合并五阶段呈现矩阵关系。数值只计算一个无偏置线性层的参数量、BF16 适配器权重存储和 alpha/r，不代表整模显存或效果。格子只表示形状，不是真实权重。
- DPO：固定构造参考 log-prob，调节参考校正差值 Δ 与 beta；分五阶段揭示偏好对、参考、策略、差值和稳定损失。仅演示单对代数，不执行训练，也不预测事实正确性。
- 焦点动效用于显示路径激活与正负相对增益，不使用滚动劫持、无限循环、粒子或新动效库。保留默认暂停、减少动画、隐藏暂停与卸载清理。
- L1 看机制，L2 做预算与数据判断，L3 复算与推导；每篇给出三个明确的自测入口。

## 验证

实现前本地浏览器断言两篇各有一个交互图解，均因实际数量为零而失败。实现后使用临时 Node/Playwright 断言计算、阶段、控件、移动溢出、主题与减少动画，并运行项目现有 check/build，不新增测试框架。
