# 前沿阅读与贡献判断

L4 不是「刚更新」的标签，也不是比 L3 多背几个模型名。它描述的是评价新工作贡献的阅读目标，不对站内旧材料的时效背书。前置要求是能理解相关方向的基线、推导与实验设置。

<PathJourney />

## 一张论文卡，六个问题

1. **问题**：原方法具体在哪种条件下失效？是否给出可检验的假设？
2. **增量**：新增的是算法、数据、系统实现还是训练配方？与最近的强基线比较了吗？
3. **证据**：是否控制模型、数据、预算与硬件？有没有必要的消融与不同种子？
4. **代价**：更高质量是否来自更多推理 token、样本、工具或人工标注？
5. **边界**：结论对哪类任务成立？论文没有证明什么？
6. **下一步**：哪个实验最可能推翻核心主张？什么仍是开放问题？

## 三条进入路线

| 主题入口 | 应追问的开放问题 | 实践产出 |
| --- | --- | --- |
| [Agentic RL](/advanced/agentic-rl) | 奖励是否真的衡量业务完成？工具环境变化后泛化如何验证？ | 奖励漏洞与分布变化的实验方案 |
| [推理模型](/advanced/reasoning-models) | 更多计算的收益来自搜索、训练还是回答长度？ | 固定成本预算下的对照设计 |
| [FlashAttention](/advanced/flash-attention) | 优化受哪些形状、硬件和带宽边界限制？ | 瓶颈假设与同负载基线 |

每个入口都是背景材料；前沿判断必须回到原论文和官方实现。对无法核实的结论写「待核」，对没有运行的实验写「实验设计」，不要写成复现成功。
