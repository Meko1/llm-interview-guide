# 视频生成（Sora 与世界模型）

视频生成最容易混淆的两句话是“看起来很真实”与“能预测真实世界”。本页围绕**如何表示时间、怎样训练和生成、如何检测错误**展开，不维护实时产品排行或分辨率承诺。图像侧基础见 [扩散模型](/multimodal/diffusion)。

## 一、视频生成难在哪？

视频不是只把图像重复多次。模型还要维持主体身份、遮挡后的物体、镜头变化、运动关系与因果顺序。

| 难点 | 可观察失败 | 为什么单帧指标不够 |
| --- | --- | --- |
| 主体一致性 | 衣服、脸、物体数量逐帧改变 | 某帧很好看仍可能跨帧漂移 |
| 时间与运动 | 跳帧、重复、动作漏阶段 | 静态相似度不测事件顺序 |
| 物理与遮挡 | 穿模、碰撞错误、物体消失 | 逼真纹理不能证明动力学正确 |
| 长时程 | 场景和故事前后矛盾 | 短片成功不代表持续 rollout 可靠 |
| 资源预算 | 显存溢出、生成慢 | 成本取决于帧率、时长、分辨率和架构 |

不能给所有模型统一“比图像贵一个量级”的数字；压缩、注意力分解、采样次数与批量都改变比例。

## 二、主流技术路线

### 路线一：扩散 + 时空建模（当前主流）

旧标题保留为路线入口，不代表本文核验了市场占比。[Stable Video Diffusion（2023）](https://arxiv.org/abs/2311.15127) 研究在图像 latent diffusion 中加入时序层，以及图像预训练、视频预训练、高质量视频微调的阶段设计。

一般流程可概括为：

```text
训练：视频预处理/描述 → 时空压缩表示 → 采样噪声与时间 → 预测目标
推理：噪声 + 文本/参考帧/控制 → 多次时空更新 → 解码 → 视频
```

时序卷积、时间注意力或时空联合注意力可以让帧间交互，但“看见前后帧”不保证物体恒存或物理正确。视频编码器也可能有损，压缩方式要按具体报告检查。

**Sora 与时空 patch。** [2024 年官方技术说明](https://openai.com/index/video-generation-models-as-world-simulators/) 本轮读取返回 HTTP 403，仅链接待核。这里保留其学习入口，但不把具体编码器结构、任意时长支持、产品规格或 scaling 结论当已核事实。

时空 patch 的一般思路是把压缩后的视频划成跨时间与空间的块，作为网络输入单位。它能统一表示不同形状的输入，不代表任何尺寸都能无约束运行；最大长度、位置编码、数据覆盖和显存仍有限制。

### 路线二：自回归生成

[VideoPoet（2023）](https://arxiv.org/abs/2312.14125) 使用 Decoder-only Transformer 与多模态 token，包含预训练和任务适配。它提供了视频不必全部用扩散生成的公开证据。

自回归能够按顺序续生成，但上下文窗口、误差积累和码率限制仍在；扩散也可以采用窗口、条件续接或分层生成。不能简化成“扩散必固定时长，自回归支持无限长度”。混合路线的好坏仍需对应版本实验。

## 三、控制与一致性技术

- **文本描述**：描述是否覆盖动作、主体、时间和镜头会影响监督；错误 caption 也会教错对应关系。
- **参考帧/图生视频**：增加外观约束，但之后的运动、遮挡和身份仍可能漂移。
- **轨迹/相机条件**：能限定部分自由度，需区分主体运动与相机运动。
- **重叠窗口/关键帧**：可延长生成并减轻边界突变，但不是解决长期记忆的保证。

训练路径和推理控制是不同层面的设计。给更长提示不一定提升控制精度，过强或冲突条件还可能降低多样性。

### 一个可复算的 token 预算

构造例：16 帧、$512\times512$ 输入，假设时间压缩 2 倍、空间各压缩 8 倍；latent 形状为 $8\times64\times64$。若 patch 大小为 $1\times2\times2$，则：

$$N=8\times(64/2)\times(64/2)=8192.$$

这不是任何产品配置。把时长翻倍，token 数翻倍；若用全局密集注意力，其注意力分数矩阵元素数约变为四倍，但整个模型 FLOPs 不必恰好四倍。分解/局部注意力、FlashAttention 等还会改变计算与存储方式。

成本还包括文本编码、生成网络评估次数、视频解码、显存传输和重试。只报“一段视频用了几秒”不能比较不同帧率、分辨率与硬件。

## 五、评估怎么做？

[VBench（2023）](https://arxiv.org/abs/2311.17982) 将视频生成质量拆成 16 个维度，例如主体一致、运动平滑和时序闪烁。分项分数有诊断意义，总分不能替代某个业务的控制与安全要求。

可操作协议：固定提示集、模型版本、采样设置、时长、分辨率与多个 seed；保留全部样本而不是精选；分别报告主体、动作、空间关系、文本跟随、物理挑战与延迟/资源。主观人评应盲化并记录指南、分歧和样本量，也不是无误差“金标准”。

**失败例**：球被箱子挡住后消失。检查遮挡前后身份、数量和轨迹；再用不同 seed、相似场景与不同镜头复测。一次视频成功不能证明物体恒存，失败也不能单凭观感定位唯一原因。

## 六、与世界模型的关系（开放题高频）

用于决策的世界模型更关注**状态与动作如何影响未来，以及预测能否支撑规划**，不只要求像素好看。下一帧预测可能捕获统计规律，但观察性数据的拟合不足以证明学到了可干预的因果关系。

[Genie（2024）](https://arxiv.org/abs/2402.15391) 描述时空 tokenizer、自回归动力学和 latent action model，提供可控制生成环境的研究例子。生成 latent 动作的环境与在真实世界安全可用的模拟器之间仍有验证距离。

可以对照两种研究目标：生成像素用于可视化/合成数据；预测表示用于状态和决策。两者不必互斥，不能把不同路线写成“乐观派 vs 唯一正道”。检验重点包括：动作干预、状态保持、长期预测误差、规划收益，以及策略迁移到真实环境的误差与风险。

视频生成可用于原型与数据探索，但“作为可靠 RL 训练环境的价值已经成立”需要具体实验；本文没有进行这类实验。
