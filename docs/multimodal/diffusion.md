# 扩散模型与图像生成

这一页以 DDPM、Latent Diffusion、DiT 和 Rectified Flow 的公开论文解释图像生成，不把商业产品名当架构证明。先分清三件事：**模型预测的量、采样器如何更新状态、文本条件在哪里进入**。理解这些，才能解释步数、引导强度和分辨率的取舍。

## 一、扩散模型的核心思想

[DDPM（2020）](https://arxiv.org/abs/2006.11239) 通过固定噪声过程构造训练样本，学习反向生成。标准噪声预测参数化可写为：

$$
x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,
\quad \epsilon\sim\mathcal N(0,I),
$$

$$
\mathcal L_{simple}=\mathbb E_{x_0,t,\epsilon}
\left[\|\epsilon-\epsilon_\theta(x_t,t)\|^2\right].
$$

$\bar\alpha_t$ 是由噪声日程决定的累计信号比例。训练时通常直接抽取 $t$ 构造 $x_t$，不是为每张图片顺序执行所有加噪/去噪步。终点是在合适日程下接近噪声分布，有限步并非字面上的“完全纯噪声”。

```text
训练：真实图 + 随机时间 + 噪声 → 带噪图 → 网络预测目标 → 损失
推理：噪声 → 网络预测 + 采样器更新 → … → 生成图
```

生成不是找回某张被加噪的原图，而是从噪声采样新数据。噪声、干净样本、velocity 等都是可能的预测参数化；“所有模型学每一步要去掉的噪声”并不准确。

## 二、与 GAN / VAE 的对比

| 路线 | 核心机制 | 常见成本/失败点 |
| --- | --- | --- |
| GAN | 生成器与判别器对抗 | 对抗训练、模式覆盖；生成可少步，但不保证质量 |
| VAE | 带潜变量的编码/解码与分布约束 | 压缩和重建取舍；模糊不是所有 VAE 的必然结果 |
| Diffusion | 学噪声分布之间的反向生成过程 | 多次网络评估、条件偏差与细节失真 |

这些类别可以组合。Latent Diffusion 使用自动编码器与去噪网络，不是 VAE 与扩散二选一。哪种“更好”必须限定数据、分辨率、任务、质量指标和生成成本。

## 三、关键技术

### 3.1 Latent Diffusion（潜空间扩散）= Stable Diffusion

沿用旧标题定位早期 Stable Diffusion 路线，不代表两个术语完全同义。[Latent Diffusion（2021）](https://arxiv.org/abs/2112.10752) 在预训练自动编码器的潜空间生成：

```text
训练图 → 编码器 → latent → 加噪与去噪学习
推理噪声 latent → 多步采样 → 解码器 → 像素图
```

压缩减少空间状态规模，也可能丢失小字、细纹理和精确几何。生成可在消费级设备运行与否，还取决于模型尺寸、精度、分辨率、batch 和 offload，不能只凭“潜空间”保证。

### 3.2 文本如何控制生成？

LDM 论文使用交叉注意力引入文本等条件：图像状态作为查询，文本编码特征提供 K/V。文本编码器、条件融合和去噪网络是不同模块；CLIP 可以提供条件特征，但不是所有文生图都只用 CLIP。

也有联合处理文本/图像 token 的结构。条件写得清楚并不保证数量、空间关系或文字内容正确，需对这些约束单独验证。

### 3.3 Classifier-Free Guidance（CFG）

[CFG（2022）](https://arxiv.org/abs/2207.12598) 结合有条件与无条件预测，不另用分类器。以噪声预测约定表示：

$$
\hat\epsilon=\epsilon_{uncond}+w(\epsilon_{cond}-\epsilon_{uncond}).
$$

此约定中 $w=1$ 等于条件预测；不同实现对 guidance 参数的定义可能不同。提高引导强度会改变条件贴合、样本多样性和失真的取舍，不是越大越“听话”。

朴素 CFG 通常需要两路网络计算，合并 batch 能改变墙钟时间但不消除计算；蒸馏 guidance 等实现不应套用同样成本估计。

### 3.4 去噪网络：U-Net → DiT

[DiT（2022）](https://arxiv.org/abs/2212.09748) 将潜空间 patch 输入 Transformer，研究模型规模、token 数与前向 FLOPs 的扩展关系；论文的 ImageNet 结果不是任何文生图任务的通用质量保证。

[SD3 对应论文（2024）](https://arxiv.org/abs/2403.03206) 使用图像与文本各自参数、双向信息交互的 Transformer 架构，讨论 Rectified Flow 的训练路径与噪声采样。它与原始 DiT 不是只改名称的同一模型，MMDiT 也不等于普通交叉注意力层。

### 3.5 Flow Matching / Rectified Flow（2024-2025 新范式）

[Flow Matching（2022）](https://arxiv.org/abs/2210.02747) 回归给定条件概率路径的向量场；它允许包括扩散路径在内的多种路径，不必然是一条直线。[Rectified Flow（2022）](https://arxiv.org/abs/2209.03003) 用直线插值构造训练目标，是相关但不应混为同义的路线。

构造约定：$x_0$ 为噪声、$x_1$ 为数据，令 $x_t=(1-t)x_0+tx_1$，学习 $v_\theta(x_t,t)$ 逼近条件速度 $x_1-x_0$。推理积分 $dx/dt=v_\theta(x,t)$。**训练配对路径是直的，不代表学到的边缘向量场轨迹处处直、一步就精确到达数据。**

“扩散就是 SDE、Flow 就是直线 ODE”过度简化：扩散也有确定性采样表述，Flow Matching 也可选非直线路径。FLUX 是相关产品/模型入口，本文未读其具体版本材料，不给参数、许可或质量排名结论。

### 3.6 采样加速

DDIM、DPM-Solver、LCM、一致性模型等是采样或蒸馏学习入口。不能把“几十步”与“1–4 步”看成同一模型任意缩步的等价操作；可用步数依赖训练/蒸馏、日程、采样器和目标质量。

应记录网络评估次数（NFE），而不只记界面的 steps。构造例：20 次更新若每次用条件/无条件两路预测，算力账本约有 40 路预测；还需加文本编码、解码器和后处理。高分辨率与 batch 的显存开销需单独测。

## 四、应用与代表

| 任务 | 控制信号 | 应当检查 |
| --- | --- | --- |
| 文生图 | 文本条件 | 数量、方位、文字、风格与版权边界 |
| 局部重绘 | 原图、mask、文本 | mask 内编辑与外部区域保持 |
| 结构控制 | 边缘、姿态、深度等 | 控制准确性、冲突条件与细节损失 |
| 风格适配 | LoRA 等参数适配 | 风格增益与身份/内容偏置，见 [LoRA](/finetuning/lora) |
| 视频 | 时序与运动条件 | 不能用单帧美感替代时序/物理检验，见 [视频生成](/multimodal/video-generation) |

## 五、扩散 vs 自回归

扩散/Flow 可在一次网络评估中更新多个位置，但需要多次评估；自回归按生成顺序构造 token，可复用缓存。并行不等于低延迟，自回归也不只用于文本。

**失败例**：生成“左边三个红杯，右边两个蓝杯”，图片美观却数量错误。扩大引导或减少步数未必修复组合关系。固定提示集、多随机种子、模型与采样器，分别记录约束满足率、人评、延迟和失败类型；不要只展示最好的一张。

## 六、高频追问

<details>
<summary>扩散模型训练时每张图要顺序去噪上千次吗？</summary>

通常不需要。训练随机采样时间和噪声直接构造带噪输入，再预测对应目标。推理才由采样器多步更新；训练离散时间数量和实际推理步数不是同一指标。

</details>

<details>
<summary>Rectified Flow 的直线训练目标为什么不保证一步采样？</summary>

网络学习的是条件速度的回归/边缘向量场，有限容量与数值积分都会有误差；训练样本直线路径不等于生成轨迹完全直。少步结果要依据对应训练或蒸馏设置验证。

</details>
