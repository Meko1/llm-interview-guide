# 阅读与分级说明

这里不是越长越好的答案库。先明确目标岗位，再沿路径学习，最后用「解释机制 → 实现最小系统 → 分析失败 → 权衡取舍」验证理解。

| 主阅读级别 | 前置知识 | 应达到的能力 |
| --- | --- | --- |
| L0 入门 | Python 基础 | 用自己的话讲清概念 |
| L1 应用 | 能调用模型 API | 搭建 RAG / Agent，初步选型和排障 |
| L2 工程 | 应用开发与服务经验 | 用质量、延迟、成本、安全数据做取舍 |
| L3 研究 | 线性代数、概率、训练基础 | 解释推导，设计消融，复现论文 |
| L4 前沿 | 能阅读相关方向论文 | 区分新贡献、实验边界与开放问题 |

**主阅读级别不是准入门槛。** 一篇文章可以跨级，先读入口与基础，再进入工程决策和研究追问。岗位标签用于推荐，不代表招聘标准。

## 对元数据诚实

- 「初次分级」由所属板块推断，尚未逐篇人工核实；「已核分级」仅代表确认了阅读级别，不等于整篇技术事实认证。
- 阅读时长根据中文字符与英文词数估算，不含代码调试、公式推导和项目实践。
- 页面底部的仓库更新日期来自 Git；它不是论文核查日期或适用版本保证。
- 本轮五篇核心页补强了取舍、失败案例与参考资料；全站其他文章仍在分批审校。

## 如何练习面试表达

1. 一分钟解释问题和机制，不依赖术语堆砌。
2. 用张量形状、数字算例或数据流说明细节。
3. 给出一个失败场景，解释为什么常见补救无效。
4. 说清替代方案、约束和下一步验证实验。
