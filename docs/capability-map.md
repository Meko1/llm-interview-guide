# 定位你的能力坐标

不是先读完所有文章，而是先明确：要解决什么问题、哪些前置还需补齐、用什么证据检验自己的判断。

<CapabilityPlanner />

## 如何使用这张地图

1. 选择目标和当前基础。经验是你提供的背景，不是系统测出的能力。
2. 选择能力节点，先独立回答情境，再核对要点与证据清单。
3. 如实声明当前状态。只有你声明可展示证据时，推荐才向后推进；这不是评分或认证。
4. 沿前置关系补齐基础，回到正文与分层自测，再交付一个具体实践产出。

路线是建议学习顺序，不是所有岗位的统一门槛，也不覆盖每个专业方向。L0–L4 描述阅读与判断深度，不是薪资、职级或就业保证。完整口径见 [阅读与分级说明](/reading-guide)。

当前声明只保留在页面内存中，刷新即清空，不上传、不存储。需要保留你的实践证据，请自行整理成笔记或项目记录。已有明确问题，可直接进入 [知识目录](/catalog) 或 [岗位学习路径](/paths/)。
