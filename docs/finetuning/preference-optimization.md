# 偏好优化方法全景（DPO 及其变体）

> RLHF 之后，「怎么用偏好数据对齐模型」演化出一大家族方法：DPO、IPO、KTO、ORPO、SimPO……面试常被追问「DPO 和这些变体的区别」。本文把这条线索理清，给出选型直觉。RLHF/PPO/DPO 推导见 [RLHF / DPO 对齐](/finetuning/rlhf)，RL 基础见 [强化学习基础](/advanced/rl-basics)。

## 一、从 RLHF 到 DPO：为什么要简化？

经典 RM + PPO 包含策略、参考、奖励、价值四种职责；不意味着四份同尺寸模型必须同时常驻。DPO 在特定 KL 正则目标和 Bradley–Terry 偏好假设下消去显式奖励学习，直接优化同一 prompt 的偏好对 $(y_w,y_l)$：

$$L_{DPO} = -\log\sigma\Big(\beta\big[\log\tfrac{\pi(y_w)}{\pi_{ref}(y_w)} - \log\tfrac{\pi(y_l)}{\pi_{ref}(y_l)}\big]\Big)$$

公式省略了相同的条件 $x$。优化的是 chosen 相对 rejected 的**参考校正差值**，不是保证两者绝对概率一升一降。原始形式为离线优化；它降低流程复杂度，不保证数据噪声或分布外行为自动消失。

## 二、DPO 的痛点与变体动机

DPO 虽好，但有几个被反复改进的点：

| 痛点 | 对应变体 |
| --- | --- |
| 需要参考模型（多一份显存） | **ORPO、SimPO**（去掉参考模型） |
| 需要成对偏好数据（贵、难收集） | **KTO**（只需「好/坏」单点标注） |
| 可分偏好持续拉大 margin；目标与长度行为不匹配 | **IPO、SimPO**（有限目标 margin / 平均 log-prob） |
| 要先 SFT 再 DPO 两阶段 | **ORPO**（SFT 和对齐一步到位） |

## 三、主流变体速览

| 方法 | 一句话 | 关键特点 |
| --- | --- | --- |
| **DPO** | 偏好数据直接优化，基准方法 | 需参考模型 + 成对数据 |
| **IPO** | 从 ΨPO 的 identity 特例推导平方目标 | 不是简单在 DPO 上另加 L2 正则 |
| **KTO** | 用「前景理论」，只需单点好坏标签 | **不需要成对数据**，标注成本低 |
| **ORPO** | SFT 阶段直接加偏好惩罚项 | **单阶段、无参考模型** |
| **SimPO** | 用平均对数概率做隐式奖励，加长度归一 | **无参考模型**，缓解长度偏置 |

### 重点理解几个

- **KTO**：现实中「成对偏好」数据难收集，但「这条回答好不好」的二元反馈到处都是（点赞/点踩）。KTO 借鉴行为经济学的前景理论，**只用单条样本的好/坏标签**就能对齐，大幅降低数据门槛。
- **ORPO**：把对齐塞进 SFT——在 SFT 损失上加一个「降低劣答相对优势」的惩罚项，**一步完成 SFT + 对齐，且不需要参考模型**，省事省显存。
- **SimPO**：用答案平均 log-prob 与目标 margin，不需要参考模型。平均改变长短回答的权重，但不保证所有长度偏差消失；DPO 的参考校正也不能仅由序列长度判断正负。

### 三种目标，三个不能混用的分母

令 $\ell_\theta(y)=\sum_{t\in M}\log\pi_\theta(y_t\mid x,y_{<t})$，$M$ 仅含有效回答 token，$T=|M|>0$。

| 方法 | 偏好信号 | 损失核心 |
| --- | --- | --- |
| 原始 DPO | $h=(\ell_\theta^w-\ell_{ref}^w)-(\ell_\theta^l-\ell_{ref}^l)$ | $-\log\sigma(\beta h)$ |
| IPO（TRL token 平均实现） | $\bar h=(\ell_\theta^w-\ell_{ref}^w)/T_w-(\ell_\theta^l-\ell_{ref}^l)/T_l$ | $(\bar h-1/(2\beta))^2$ |
| SimPO | $g=\ell_\theta^w/T_w-\ell_\theta^l/T_l$ | $-\log\sigma(\beta g-\gamma)$ |

IPO 的平均处理这里明确绑定到所读 TRL 实现，不冒充所有论文/实现统一口径。SimPO 的 $\gamma$ 是目标奖励 margin；beta 不是学习率。

**构造算例**：chosen 的 log-prob 和为 -6、长度 3，rejected 为 -8、长度 8；参考两者分别为 -7、-9。DPO 校正差是 `1−1=0`，损失 `log 2`。若 beta=1、gamma=0.5，SimPO logit 是 `(-2)-(-1)-0.5=-1.5`，损失约 `1.7014`。两种目标此刻的信号不同，不意味着哪个答案客观更好；它们使用的参考和分母不同。

## 四、在线 vs 离线偏好优化

- **离线**（DPO 系）：用固定的偏好数据集，简单稳定，但模型只能从「别人采的样本」里学，探索受限、易分布偏移。
- **在线/迭代**：重新采样、打标和优化能补数据覆盖，也增加评审漂移、奖励利用与成本。是否更好必须按相同采样/训练总预算比较。
- 趋势：**迭代式偏好优化**（采样→打标→DPO→再采样）成为高质量对齐的常见配方，介于纯离线 DPO 和完整 PPO 之间。

## 五、和 RLHF（PPO/GRPO）怎么选？

| | DPO 系（偏好优化） | PPO / GRPO（在线 RL） |
| --- | --- | --- |
| 复杂度 | 低（监督式） | 高（采样 + RL） |
| 数据 | 偏好对/单点标签 | prompt + 奖励信号 |
| 探索能力 | 弱（离线）/中（迭代） | 强 |
| 适合 | 通用对齐、资源有限 | 可验证奖励（数学/代码）、追求上限 |

可先用已有可靠偏好数据做低复杂度基线；只有需要探索且奖励可验证时才评估在线 RL。这里是实验次序，不是质量排名；见 [DeepSeek 专题](/models/deepseek)。

## 六、面试专项：偏好优化方法怎么选

面试里不要把所有方法背成论文名，建议用 **数据形态、是否需要参考模型、是否在线探索、适合任务** 四个维度来答：

| 方法 | 需要的数据 | 是否需要参考模型 | 适合场景 | 面试关键词 |
| --- | --- | --- | --- | --- |
| DPO | 成对偏好 `(chosen, rejected)` | 需要 | 通用对齐、资源有限、开源微调 | 简单稳定、无 RM、离线 |
| KTO | 单条好/坏标签 | 通常需要 | 线上点赞/点踩多，但难构造成对 | 降低标注门槛 |
| ORPO | SFT 数据 + 偏好信号 | 不需要 | 想把 SFT 和对齐一步完成 | 单阶段、无参考模型 |
| SimPO | 成对偏好 | 不需要 | 担心 DPO 长度偏置、显存紧张 | 平均 log prob、长度归一 |
| GRPO | prompt + 一组回答 + 奖励 | 原始形式含参考 KL；不需独立 Critic | 有区分奖励的在线训练 | 组内优势与长度 reduction |

### 选型口径

- **我只有一批高质量 chosen/rejected 偏好对**：先用 DPO，工程最稳。
- **只有线上点赞点踩**：先区分答案质量、用户情绪和曝光选择偏差；KTO 不要求配对，但标签不是自动可靠，不能把不同 prompt 拼成标准 DPO 对。
- **我想少放一个参考模型、省显存**：看 ORPO / SimPO，但要评估效果是否稳定。
- **代码/数学能验证**：比较监督基线与在线探索；记录验证器漏检、采样预算、长度和多次运行，而不宣称 GRPO 有统一更高上限。
- **我做金融/客服安全对齐**：不能只优化拒答率，要同时看正常问题误拒率和帮助性。

**一句话总结：** DPO 系解决“低成本利用偏好数据”，GRPO/RLVR 解决“有可验证奖励时继续提升能力上限”；方法选型先看数据和评估，不先看论文热度。

## 高频追问

**Q：DPO 为什么能不用奖励模型？**
DPO 的推导利用了「RLHF 最优策略与奖励函数之间存在解析关系」，把奖励函数用策略本身表示出来，代入 Bradley-Terry 偏好模型后，奖励模型被消掉，问题变成对策略的直接监督优化。本质是把两阶段（训 RM + RL）合成一个闭式损失。

**Q：KTO 相比 DPO 的最大优势？**
数据。DPO 要成对偏好数据（同一问题的优答+劣答），收集贵；KTO 只要单条样本的「好/坏」二元标签（如线上点赞/点踩），数据易得得多。它用前景理论建模，适合「有大量单点反馈、难凑成对」的现实场景。

**Q：ORPO 和 SimPO 都说「不要参考模型」，怎么做到的？**
ORPO 把偏好惩罚直接加进 SFT 损失，对齐发生在 SFT 阶段，没有「相对参考模型」这一步；SimPO 用「答案平均对数概率」当隐式奖励、配合一个目标 margin，不需要参考模型算相对量。去掉参考模型省一份显存、简化流程。

**Q：DPO 训练后答案越来越长是什么原因？**
先查偏好标注的长度相关性、策略/参考评分范围、EOS、截断和推理预算。序列 log-prob 求和不能单独推出必偏长；做长度匹配切片和独立正确性评测后再选择目标变体。

**Q：什么时候该用 PPO/GRPO 而不是 DPO？**
当固定数据覆盖不足、在线采样有机会产生更好的轨迹且奖励足够可靠时，可以实验 PPO/GRPO。探索机会不是效果保证，尤其要计入丢弃样本、验证器执行和长轨迹成本。

## 一个失败闭环比论文名更有说服力

偏好模型选中「看起来完整但引用错误」的长回答，DPO 后 Judge 胜率上涨，专家正确率却下降。先按长度匹配复评，再补证据核查标签，冻结验收集；若只换 SimPO 而保留错误标签，根因仍在。正常问题误拒和风险问题拒答必须分别报告。

**Q：迭代 DPO 是什么？为什么比普通 DPO 好？**
普通 DPO 用一份固定偏好数据；迭代 DPO 是「用当前模型采样新回答 → 打偏好标签 → DPO 更新 → 再采样」的循环，让训练数据始终来自最新模型的分布，缓解离线 DPO 的分布偏移、补回部分探索能力，效果更接近 RLHF。
