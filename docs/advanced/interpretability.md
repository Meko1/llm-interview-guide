# 机制可解释性（Mechanistic Interpretability）

机制可解释性尝试给模型内部计算提出**能被干预实验推翻的机制解释**。它不是读取意识、证明模型没有隐藏目标，或给整模型签发安全证书。前置：[Transformer](/basics/transformer)、[表示学习](/basics/embeddings)、[Logits 与损失](/basics/logits-loss)。

## 面试先背这几句话

- 行为测试问“输出如何”，机制研究问“哪些内部变量在什么条件下影响输出”。后者仍依赖样本、指标和干预设计。
- 特征不必等于神经元；一个方向可涉及多个坐标，一个坐标可参与多个特征。
- SAE 提供稀疏的**近似分解**，可读标签、低重建误差、因果作用和覆盖完整性是四个不同要求。
- 探针是可预测性证据；patching 是指定干预下的效应证据，不自动成为自然计算的唯一解释。
- 与 [行为对齐](/finetuning/rlhf) 和 [安全评测](/advanced/safety) 互补，但不能以“内部理解”替代外部授权边界。

## 一、为什么要做机制可解释性？

若幻觉只在某类上下文出现，重复改 prompt 可能掩盖错误。机制假说可以指导定位：是注意力搬错实体、事实方向改变，还是输出竞争？随后用反事实输入与干预区分假说。

| 想回答的问题 | 需要的证据 | 单独不足的证据 |
| --- | --- | --- |
| 某属性能否从激活读出 | 留出集探针、标签随机化对照 | 训练集高准确率 |
| 某内部变量是否影响答案 | 对照干预与输出差异 | 只看激活热图 |
| 发现的回路覆盖多少行为 | 跨样本/模板/模型的复验 | 一个成功案例 |
| 干预能否安全用于服务 | 质量与安全回归、剂量曲线 | 定向改变话题的演示 |

MI 可发现局部机制和可检验风险；“没发现欺骗特征”不证明没有欺骗，“发现危险相关特征”也不证明模型必然实施危险行为。

## 二、叠加（Superposition）：一切困难的根源

旧标题保留；叠加是重要困难，不是所有解释问题的唯一根源。[Toy Models of Superposition](https://transformer-circuits.pub/2022/toy_model/index.html) 在合成稀疏输入的 ReLU 玩具网络中研究：当特征数超过表示维度，模型可以用非正交方向压缩，但须承担干扰并进行非线性过滤。其结论是特定训练目标和数据设置下的机制，不是所有神经元都多义的定理。

写成字典形式更诚实：

$$x=b+\sum_{j=1}^{m}f_j(x)d_j+\epsilon(x),\qquad m>d.$$

$\epsilon$ 是没有解释掉的残差。过完备字典的列不可能全部严格正交；“近似正交”仍需看内积与同时激活造成的干扰。举例 $d_1=(1,0),d_2=(0,1),d_3=(1,1)/\sqrt2$：三方向放进二维，$d_1^Td_3=1/\sqrt2$，明显存在交叉响应。稀疏激活有助于减少同时干扰，却不能保证可唯一恢复。

## 三、稀疏自编码器（SAE）：把叠加解压出来

一种 ReLU SAE 的目标是：

$$f=\mathrm{ReLU}(W_{enc}(x-b_{dec})+b_{enc}),\quad \hat x=W_{dec}f+b_{dec},$$
$$\mathcal L=\|x-\hat x\|_2^2+\lambda\|f\|_1.$$

重建项鼓励保存激活，稀疏项鼓励少数活跃方向，**二者均不直接优化“人类概念单义”**。还需归一化/约束 decoder 列范数，否则增大 decoder、缩小 feature 幅度就可能降低稀疏罚而保持重建，改变 $\lambda$ 的含义。

### SAE 的变体（面试高频）

| 方法 | 设计动机 | 不能保证的事 |
| --- | --- | --- |
| ReLU + L1 | 重建与稀疏折中 | 真实特征唯一可识别 |
| TopK | 显式控制活跃数量 | 不表示无重建或选择偏差 |
| Gated / JumpReLU | 将开关/阈值与幅度处理分开 | 不普遍优于其他方法 |
| Transcoder | 近似模块输入到输出，利于分析计算连接 | 不是残差重建 SAE 的同一对象 |

这里只解释变体动机，未逐一读取其实现或比较实验。[Scaling Monosemanticity](https://transformer-circuits.pub/2024/scaling-monosemanticity/index.html) 的实际方法段研究 Claude 3 Sonnet **一个中间残差层**，报告重建解释至少 65% 激活方差；这不是解释 65% 模型推理、安全性或输出正确率。

### SAE 的现存难题

- 字典大小/种子改变，标签可能分裂、合并或吸收；需要匹配方向并报告稳定性。
- 平均重建误差可能掩盖稀有安全任务的误差。将激活替换为重建后，还需测任务损失与行为变化。
- 高激活样本只显示特征最显眼的一面；应加入随机样本、相近但不含目标概念的负例和多语言例。
- 自动命名是辅助假说，不是特征真值。裁判校准见 [独立人工参照](/evaluation/judge-calibration)。

## 四、回路（Circuits）：特征如何连成算法

回路描述多个组件如何协同实现某个子任务。Induction head 的常用直觉是前文 `A B`、之后再次见 `A` 时帮助预测 `B`；这不证明所有 in-context learning 都来自一对头。IOI 是在受控实体模板上识别间接宾语的研究任务，不应把一个模型/模板的头集合称为整模型完整逆向。

从候选机制走向实验，应区分**恢复**与**破坏**：

| 运行 | 构造的正确—错误 token logit 差 |
| --- | ---: |
| clean 输入 | 4 |
| corrupted 输入 | 0 |
| corrupted + clean 激活 patch | 3 |
| clean + 候选组件消融 | 1 |

恢复比率 $(3-0)/(4-0)=0.75$；消融下降 $4-1=3$。这只说明所选输出指标和输入对上的效应。归一化恢复可能小于 0 或大于 1，分母接近零时不稳定；不能叫“解释了 75% 智能”。冗余路径、干预引起的分布外激活和组件相互作用还需另测。

## 五、可解释性工具箱对比

| 工具 | 回答的问题 | 关键对照 |
| --- | --- | --- |
| Probing | 给定激活可否预测标签 | 留出样本、低容量探针、随机标签 |
| Logit Lens | 中间表示经输出投影如何排序 token | normalization 与表示空间错配 |
| Activation Patching | 替换指定激活后指标如何改变 | 无关位置 patch、多个 corruption、同分布替换 |
| Ablation | 删除/替换组件的效应 | 零值与均值消融差异、冗余回路 |
| SAE | 稀疏方向能否重建和被一致解释 | 误差项、死特征、标签稳定性 |
| Attribution graph | 近似模型/归因假设下的连接 | 用原模型干预验证关键边 |

热图与归因边可以提供候选，不自动证明因果。探针失败也不证明信息不存在：非线性表示、样本不足或标签噪声都可造成失败。

## 六、特征操控与下游应用

原论文在指定 prompt 格式下将 SAE 特征钳到较高/较低值，观察模型输出改变；金门大桥特征是直观例子。**干预的有效性是研究证据，安全和特异性是另一个实验问题。**

设 $x'=x+\alpha d_j$，应至少扫 $\alpha$ 的正负剂量，比较无关方向等范数干预，记录目标行为、非目标质量、拒答和失真。强干预可能离开自然激活分布，诱发原本不会出现的行为。

真实性探针、CoT 忠实性审查、拒答方向操控可作为研究线索，不宣称能通用检测谎言、恢复真实目标或安全去掉“审查”。服务使用必须保留模型外策略、授权和回归门禁。

## 七、局限、争议与前沿

研究交付应是一张**机制证据卡**而不是解释彩图：模型/权重、层/位置、输入分布、候选变量、corruption 方法、指标、对照、效应区间、失效样本、未解释残差。也应记录选中候选前试过多少假说，避免只展示成功干预。

主要边界：局部机制未必跨模板泛化；近似字典和回路可能漏掉并行路径；词语标签可能过度人格化；模型更新后结论要复验。前沿研究入口包括跨层 transcoder、归因图和权重分析，本文不作完整性或最新排名判断。

## 高频追问

**重建好就等于忠实吗？** 不等于。激活误差小不保证关键决策方向误差小；需要测原模型与重建替换后的任务行为，再对关键特征做干预。

**patching 是因果吗？** 对“指定替换导致指定指标变化”可以做因果解释；对“自然计算一定仅靠此组件”不能。替换是否合理、是否引入分布外状态和干预相互作用都需检查。

**SAE 必须过完备吗？** 过完备是容纳更多方向的一种设计，不是找到真实概念的必要充分条件。更多格子也可能是死特征或重复特征。

**Explainability 与 MI 的区别？** 前者常面向决策说明和使用者理解，后者研究内部机制；两者都需忠实性证据，不能断言合规一定接受某类事后解释。
