# 扩散语言模型（Diffusion LLM）

扩散语言模型把“决定下一个 token”改为“根据部分可见文本，逐轮恢复未知位置”。它改变的是**生成分布和采样路径**，不是把自回归推理引擎换个调度器。前置：[扩散模型](/multimodal/diffusion)、[解码策略](/basics/decoding)。本文以 LLaDA 的掩码生成和 SEDD 的离散得分为具体参照；不把产品宣传速度当可复现结果。

## 面试先背这几句话

- 一轮网络计算可以预测多个未知位置，但预测不等于全部提交，网络调用数也不等于端到端延迟。
- 双向条件适合利用左右已知文本；它不自动保证 JSON 合法、数学正确或全局一致。
- 掩码预测器的局部概率不等于最终输出的精确联合概率，训练目标与采样器要分开解释。
- 应比较**同质量、同输出长度、同硬件和同并发**的延迟/吞吐，而不是只比较步数。

## 一、为什么要挑战自回归？

| 需求 | 改变生成方式的动机 | 尚需验证的代价 |
| --- | --- | --- |
| 多位置填洞 | 同时利用固定的左右上下文 | 槽位间依赖能否在有限轮数内解决 |
| 降低串行深度 | 一轮预测多个位置 | 每轮处理全序列的计算和激活开销 |
| 修改草稿 | 允许某些位置重新参与去噪 | 采样器是否真的允许改写已提交 token |

AR 也能通过 FIM 训练利用右侧条件，或通过外层编辑循环修订。DLM 的研究问题是把这些行为放进生成过程后，质量—预算曲线是否改善，而不是宣称 AR 无法编辑。

## 二、离散扩散：文本版的加噪与去噪

token ID 是类别编号，直接给 ID 加高斯噪声没有语义距离意义；也有在连续 embedding 空间扩散的研究，不能因此说文本扩散只有一种实现。

### 2.1 Masking Diffusion（掩码扩散，主流）

以 LLaDA 为例：采样噪声比例 $t$，独立以概率 $t$ 将原文 token 替换为 mask，网络预测被遮住的原 token。训练覆盖不同信息量的输入，使采样能从高噪声逐步进入低噪声。

官方 `generate.py` 中，`get_num_transfer_tokens` 将提交数分配给采样步，`low_confidence` 分支按置信度挑选**仍为 mask 的位置**。已经提交的位置经 `torch.where(mask_index, x0, x)` 保留。因此这里的 remasking 名称不意味着任意重写已提交文本。示意轨迹：

| 轮次 | 当前未知位置数 | 本轮提交数 | 之后未知位置数 |
| --- | ---: | ---: | ---: |
| 初始 | 8 | 0 | 8 |
| 1 | 8 | 2 | 6 |
| 2 | 6 | 2 | 4 |
| 3 | 4 | 2 | 2 |
| 4 | 2 | 2 | 0 |

这是构造的计数例，不保证 token 正确，也不是实测性能。某轮同时预测全部位置，实际只提交其中两个。

### 2.2 Score-based Discrete Diffusion（离散得分扩散）

SEDD 用离散状态概率比的得分表示反向过程，提出 score entropy 目标。连续时间描述的是跳转时间，**状态仍离散**；不能把连续图像 score 直接当作对 token ID 的梯度。具体噪声核、采样离散化和网络参数化决定实现。

### 2.3 两条路的对比

| 问题 | 掩码预测参照：LLaDA | 离散得分参照：SEDD |
| --- | --- | --- |
| 网络学习什么 | 原 token 的条件预测 | 离散状态间概率比相关得分 |
| 训练目标 | 按噪声时间加权的重构损失 | score entropy |
| 推理须固定什么 | mask 调度、提交规则、块长 | 噪声核、反向采样器、离散步数 |

这不是互斥的全部分类：吸收态掩码也可由连续时间离散过程描述。

## 三、代表工作速览（2024-2026）

| 阅读入口 | 可以从实际已读材料确认的内容 | 不应顺手外推 |
| --- | --- | --- |
| [LLaDA](https://arxiv.org/abs/2502.09992) | 从头预训练与 SFT；掩码前向、反向生成；优化似然下界 | 所有任务优于 AR、固定成本优势 |
| [SEDD](https://arxiv.org/abs/2310.16834) | 离散 score entropy；论文设置内的质量—网络调用数比较 | 同质量服务延迟倍数、首创排名 |
| Dream、Mercury、DiffuLLaMA、DiffuGPT | 作为进一步查阅入口保留 | 本文未逐一读取其版本、训练账本或服务基准 |
| DiffuSeq / GENIE | 连续表示文本扩散的阅读线索 | 不将不同表示空间的模型混为同一采样器 |

标题保留旧锚点；此表不是截至 2026 年的完整产品名单或榜单。

## 四、DLM vs AR 全维度对比

| 维度 | AR | 本文的掩码 DLM |
| --- | --- | --- |
| 概率计算 | 因果条件概率乘积 | 局部去噪概率不直接给出精确序列概率 |
| 采样顺序 | 通常逐 token，验证可批量 | 按轮/块提交多个位置 |
| 注意力与缓存 | 已生成前缀的隐藏状态可因果复用 | 双向输入变化可能使旧 K/V 失效 |
| 输出长度 | EOS 与服务上限共同控制 | 预设长度或块式扩展，加结束策略 |
| 约束满足 | 需要约束解码或校验 | 同样需要约束解码或校验 |
| 质量与资源 | 取决于模型和预算 | 取决于模型、轮数、调度和块长 |

## 五、推理为何能快 10 倍以上？

**旧标题保留，但不承诺十倍加速。** 对输出 $L$ 个 token，令 AR 平均 decode 一步耗时为 $a$，DLM 一轮耗时为 $d$、轮数为 $K$，公共与各自前处理成本为 $P_{AR},P_D$：

$$T_{AR}=P_{AR}+La,\qquad T_D=P_D+Kd.$$

构造值：$L=512,K=32,a=1\,\mathrm{ms},d=12\,\mathrm{ms},P_{AR}=P_D=20\,\mathrm{ms}$，则 $T_{AR}=532\,\mathrm{ms}$，$T_D=404\,\mathrm{ms}$，比值约 $1.32$，**不是** $L/K=16$。若 DLM 单轮 20 ms，则反而更慢。上述成本须用真实 profiler 测量。

少轮采样可能减少重复权重读取，但全序列 attention/MLP 工作、classifier-free guidance 的额外计算、调度和传输都在总账里。投机解码是对目标 AR 分布的验证加速，不是 DLM 内建的等价算法。

## 六、训练成本与挑战

每个训练样本通常只抽样一个噪声水平，不必在一个优化步里展开全部去噪链。不能由“推理多轮”推出“训练每 token 必然更贵”。应分别记录训练 token、预测位置数、总 FLOPs、设备时和达到同质量所需预算。

难点包括高噪声时信息不足、低噪声位置较少导致估计方差、训练目标与最终任务指标不一致，以及采样调度变化引起的质量变化。与 AR 的比较应匹配数据、规模、预算、模板和评测，而不是仅匹配参数量。

## 七、什么场景 DLM 已经/可能率先落地？

- **填洞/编辑候选**：固定已知位置，测编辑范围是否越界，比较同任务 AR-FIM 基线。
- **JSON/SQL**：先测 schema/语法合法率，再测语义正确性；双向注意力不代替 parser 或授权。
- **流式服务**：区分暂定文本和不可撤回的提交文本；块提交可以流式展示，但增加首块延迟和停止处理设计。
- **长文本**：固定上下文与输出长度，观察跨块一致性、EOS 行为和质量随轮数变化，不引用未核实的能力排名。

## 八、与其它非 AR 方案的关系

| 方案 | 主要改变 | 与 DLM 的区别 |
| --- | --- | --- |
| [投机解码](/inference/speculative-decoding) | 草稿与目标验证 | 保留目标分布需满足相应校正条件 |
| Medusa / EAGLE | 多 token 提议或特征预测 | 验证方式和是否精确取决于算法 |
| [Mamba](/advanced/state-space-models) | 序列混合器 | SSM 可以保持自回归生成；不是扩散 |
| BERT / MLM | 遮蔽位置预测 | 噪声分布、似然目标和多步采样不由 MLM 名称自动给出 |
| NAT | 非逐 token 生成的一类方法 | 不可把全部非自回归方法称为扩散 |

## 九、面试可用的公式与直觉

在线性掩码概率的设定下，一个序列的重构目标可写为：

$$\mathcal L=\mathbb E_{t,x_0,x_t}\left[\frac1t\sum_{i:x_t^i=\mathrm{MASK}}-\log p_\theta(x_0^i\mid x_t)\right],\quad t\in(0,1].$$

$1/t$ 是目标中的时间权重，不是“越接近真值就主观更重要”的配方。构造 $L=4,t=0.5$，实际遮住两处，预测真 token 的概率为 0.8、0.5，则这次序列损失为 $2[-\log0.8-\log0.5]\approx1.8326$；若按原序列长度平均则为 $0.4581$。按已遮住位置平均是另一分母，不能混用。$t=0$ 不直接代入；实现的截断/采样范围应查配置。似然下界不是精确困惑度。

## 高频追问

**LLaDA 与 BERT 只是换 mask 比例吗？** 不是。生成目标、噪声覆盖、训练权重和从全 mask 出发的采样协议共同定义模型；官方生成调用没有显式 `t` 参数，不能一概断言所有实现都加时间 embedding。

**固定 prompt 能直接缓存 K/V 吗？** token 固定不等于隐藏状态固定。若 prompt 能双向关注变化的输出，深层 K/V 仍会改变；只有证明注意力依赖不变、或明确接受近似误差后，才可复用。

**如何把 AR 改为 DLM？** 权重初始化、注意力 mask、特殊 token、训练目标与采样器均需核查。这里不承诺训练 token 数、步数或“便宜若干量级”。

**怎样做偏好对齐？** 先定义优化的是输出边际概率、下界代理还是去噪轨迹概率。后者需纳入各步采样/提交规则；不能将局部 token log-prob 无条件塞入 AR 的 PPO/DPO 公式。
