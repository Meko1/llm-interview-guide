# 预训练目标与数据

> 预训练是大模型一切能力的根基，「烧钱最多、决定上限」的一步。本文深入预训练目标、数据流水线、训练范式与并行、以及继续预训练等高频考点。算力与并行细节见 [分布式训练](/pretraining/distributed-training)，规模规律见 [缩放定律](/pretraining/scaling-law)。

## 一、什么是预训练？

预训练（Pre-training）= 在**海量无标注文本**上做**自监督学习**，让模型学到语言规律和世界知识，产出**基座模型（Base Model）**。

- **自监督**：训练目标从数据本身构造（如「预测下一个词」），不需要人工标注——这是能利用万亿级语料、能 scale 的前提。
- Base 以续写目标训练，可能通过上下文示例完成任务，但不默认满足稳定对话/安全要求；[SFT](/finetuning/finetuning) 和 [对齐](/finetuning/rlhf) 用于进一步调整行为。

## 二、预训练目标

不同架构对应不同的自监督目标：

| 目标 | 全称 | 做法 | 代表 |
| --- | --- | --- | --- |
| **CLM** | Causal LM（因果语言建模） | 预测下一个 token，单向 | GPT、LLaMA |
| **MLM** | Masked LM（掩码语言建模） | 随机遮盖约 15% token 让模型还原，双向 | BERT |
| **PrefixLM** | 前缀语言建模 | 可见前缀采用双向注意力，后续目标因果生成 | 前缀目标变体 |
| **Span Corruption** | 片段还原 | 输入删除片段并放 sentinel，目标生成被删片段 | T5；GLM 使用相关空白填充目标 |

**主流 LLM 用 CLM（下一个 token 预测）**，原因：训练目标统一、能利用全部文本（每个位置都有监督信号）、天然适配生成与对话、规模扩展表现好、in-context learning 强。

损失函数是**交叉熵**——让模型预测的下一个 token 概率分布尽可能接近真实的下一个 token：

$$\mathcal{L} = -\frac{1}{T}\sum_{t=1}^{T} \log P_\theta(x_t \mid x_{<t})$$

> 训练用 **teacher forcing**：每个位置都用真实前文（而非模型自己的预测）作为条件，从而所有位置可并行计算损失。

公式中的 T 应是参与 loss 的有效目标数，不含 padding 或被屏蔽目标。实现需错位一位：位置 t 的 logits 对齐 token t+1；不能同时看见答案又预测自己。构造目标概率 0.5、0.25 时，平均自然对数交叉熵为 `−(ln 0.5+ln 0.25)/2≈1.0397 nats/token`，PPL≈2.828。不同 tokenizer 的 token 粒度不同，不能直接用 PPL 判跨模型质量。

packing 要声明文档间是否允许注意力跨界、是否重置位置、EOS 如何插入。跨文档预测可以是配方选择，但若原本需要独立样本隔离，就不能只拼接文本而忽略 attention/loss mask。

## 三、训练数据：质量决定上限

> 「Garbage in, garbage out」——数据质量往往比数量更决定模型上限。近年共识：**数据是大模型的核心竞争力**。

### 3.1 数据来源

网页（Common Crawl）、书籍、代码（GitHub）、百科、论文（arXiv）、问答社区、新闻等。不同来源贡献不同能力（代码提升推理、书籍提升长文连贯、多语言数据提升跨语言）。

### 3.2 数据处理流水线（高频考点）

```
原始语料(数十 TB)
  │ 1.清洗     去 HTML/乱码/过短过长/低质页面
  │ 2.去重     文档级+句子级(MinHash/SimHash)
  │ 3.质量过滤  规则 + 分类器(「像不像维基」)
  │ 4.去毒/隐私 过滤有害内容、PII
  │ 5.配比混合  调代码/中英文/数学等比例
  │ 6.Tokenize 切 token、拼成定长序列、打包
  ▼
训练就绪的 token 序列(数万亿 token)
```

每一步都关键：

- **去重**：减少重复权重与原文复现风险，但阈值会改变分布；独立验证后选择强度，不默认越多越好。
- **质量过滤**：用分类器筛掉低质内容是性价比极高的一步（FineWeb、Phi 系列都强调）。
- **配比（Data Mixture）**：按有效训练 token 而非条数统计；用等 token/等计算消融验证任务改善，不能把“加代码”当通用推理提升保证。

冻结验证/测试集后，交叉检测题干、答案和解释并保留血缘，见 [污染审计](/pretraining/contamination-audit)。内部去重与评测去污染不是一回事。

### 3.3 数据量级

规模没有统一门槛。预训练按处理 token（含重复）计，SFT 的样本条数还需乘实际长度与 epoch，不能直接比较 token 与条数；预算与数据可行域见 [训练预算](/pretraining/compute-budget)。

## 四、训练范式与并行

超大模型单卡放不下，必须分布式并行（详见 [分布式训练](/pretraining/distributed-training)）：

- **数据并行（DP）**：每卡放完整模型、喂不同数据、同步梯度。
- **张量并行（TP）**：把单层大矩阵切到多卡（层内拆分，机内高带宽）。
- **流水线并行（PP）**：把不同层放不同卡（层间拆分，有流水线气泡）。
- **ZeRO / FSDP**：把优化器状态、梯度、参数分片到多卡，大幅降单卡显存。

超大模型训练通常是这几种的组合（**3D 并行**）。**混合精度（BF16）+ 梯度累积 + 梯度检查点** 是标配；BF16 因动态范围大、不易溢出成为首选。

## 五、训练全景与稳定性

完整训练还涉及：学习率 warmup + 余弦衰减、梯度裁剪、loss spike 处理等（详见 [训练深入](/advanced/training-internals)）。超大规模训练的「炼丹」难点在于**稳定性**——一次 loss 飙升可能毁掉几天的算力。

## 六、继续预训练（Continue Pre-training）

在已有基座上用领域语料继续优化语言建模目标，可再做 SFT。通用数据回放用于降低遗忘风险，但不是保证；同时监控领域验证与通用能力回归，保留未训练过的来源切片。

精确续训需要模型、优化器、学习率调度、RNG、数据游标、累计有效 token 与配置快照。只加载权重做领域继续训练是新阶段，不应声称恢复了原优化轨迹。先小规模验证吞吐/显存和数据可用量，再选择 N、D 与截止时间。

## 七、高频追问

**Q：预训练为什么用自监督而不是监督学习？** 监督学习需人工标注，无法覆盖万亿语料。自监督用「预测下一个 token」等从数据本身构造的目标，无需标注，才能利用海量无标注文本——这是大模型 scale 的前提。

**Q：CLM、MLM、Span Corruption 的区别？主流用哪个？** CLM 预测下一 token（单向，GPT/LLaMA）；MLM 还原被遮盖 token（双向，BERT）；Span Corruption 还原连续片段（T5）。主流用 CLM——目标统一、用满数据、适配生成。

**Q：BERT（MLM）和 GPT（CLM）的本质区别？** BERT 双向、看得到全文，擅长理解类任务（分类/NER/检索）但不能直接生成；GPT 单向、只看前文，天然适配自回归生成。

**Q：为什么去重这么重要？** 重复数据导致过度记忆、泛化下降、算力浪费，还可能放大某些偏见。充分去重（MinHash 等）能显著提升下游效果，是数据流水线的关键一步。

**Q：数据配比为什么重要？** 不同来源塑造不同能力——代码数据提升推理与结构化能力、多语言数据提升跨语言、数学数据提升计算。配比直接决定模型的能力分布，是预训练「炼丹」的核心调参点。

**Q：预训练和微调的数据量怎么比？** 统一统计实际参与 loss 的处理 token、独特数据量与重复次数；条数和 token 不是同一单位，SFT 也可能改变知识。

**Q：什么是继续预训练？和微调有什么区别？** 继续预训练在基座上用领域语料继续做 CLM（注入领域知识，仍是自监督、数据量大）；微调用指令-回答对教模型遵循指令（监督、数据量小）。行业大模型常「继续预训练 + SFT」组合。

**Q：teacher forcing 是什么？有什么问题？** 训练时使用真实前文、并行计算错位目标；生成使用模型自身输出，误差可能累积，不能只凭训练 loss 证明长生成稳定。

目标比较见 [T5 原论文](https://arxiv.org/abs/1910.10683)；错位实现可核对 [Transformers v4.45.2 LlamaForCausalLM](https://github.com/huggingface/transformers/blob/v4.45.2/src/transformers/models/llama/modeling_llama.py)。此处固定版本用于解释语义，不代表当前 API 调用配方。
