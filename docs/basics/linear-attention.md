# 线性注意力与混合架构

> 标准注意力的 $O(n^2)$ 复杂度是长序列的根本瓶颈。一条研究主线试图把它降到**线性** $O(n)$——线性注意力、RWKV、RetNet，以及把它们和 Transformer 缝在一起的**混合架构**（Jamba 等）。这是 2024–2025 长上下文与高效推理的前沿。标准注意力见 [Attention 与变体](/basics/attention)，状态空间模型见 [Mamba/SSM](/advanced/state-space-models)。

## 一、问题：注意力为什么是 O(n²)？

标准自注意力要算「每个 token 对每个 token」的相似度，得到 $n \times n$ 的注意力矩阵：

- 密集注意力核心算术量随序列长度平方增长；朴素实现存储平方矩阵，但 FlashAttention 不物化它，不能把显存也一概说成平方；
- 推理时 KV Cache 随序列**线性**增长，但每步注意力仍要扫全部历史。

序列从 1K 到 100K，平方项让成本爆炸——这是长上下文的核心障碍。

## 二、线性注意力的核心思想

标准 softmax 注意力不能直接用结合律把 softmax 移到 $K^TV$ 上。核化线性注意力改用可分解的相似度 $\phi(q)^T\phi(k)$；它可以是替代核，也可以是 softmax 核的近似，二者不要混淆。以下用不带归一化的矩阵乘法说明结合律，不能当作标准注意力的等价式：

```
标准： (Q · Kᵀ) · V   先算 n×n 矩阵 → O(n²)
线性： Q · (Kᵀ · V)   先算 d×d 矩阵 → O(n)
```

若核特征维为 $m$、value 维为 $d_v$，状态是 $m\times d_v$，不必等于 $d\times d$。采用列向量，带归一化的因果版本维护两个累积量：

$$S_t=S_{t-1}+\phi(k_t)v_t^T,\qquad z_t=z_{t-1}+\phi(k_t)$$

$$o_t=\frac{S_t^T\phi(q_t)}{z_t^T\phi(q_t)}$$

分母需非零，实践中需控制数值稳定性；非负核特征常用于得到非负归一化权重。对固定 $m,d_v$，总计算约为 $O(nmd_v)$、单步状态存储为 $O(md_v)$。若特征维也增长，或混入全注意力层，就不能继续宣称整体常数缓存。

好处很明显：推理时不再需要随长度增长的 KV Cache，只需一个**固定大小的状态**，长上下文的显存和速度问题大幅缓解。

## 三、代表方法

| 方法 | 一句话 | 特点 |
| --- | --- | --- |
| Linear Transformer | 用核函数去 softmax，注意力变 RNN | 线性注意力的奠基 |
| **RWKV** | 把类 RNN 的递推做成可并行训练的「线性注意力」 | 训练像 Transformer、推理像 RNN |
| **RetNet** | 保留多尺度衰减的「retention」机制 | 训练并行 / 推理递推 / 分块三种模式 |
| **Mamba（SSM）** | 选择性状态空间模型，本质也是线性递推 | 见 [状态空间模型](/advanced/state-space-models) |
| GLA、DeltaNet 等 | 带门控/增量更新的线性注意力新变体 | 提升表达力 |

共同探索方向是并行/分块训练与递推推理，但更新方程和并行内核不同，不能据此承诺「像 Transformer 一样快」。[Linear Transformer](https://arxiv.org/abs/2006.16236)讨论核特征结合律；[Mamba-2](https://arxiv.org/abs/2405.21060)研究结构化状态空间对偶，不等于把全部 SSM 命名为同一线性注意力算法。

## 四、代价：线性注意力为什么没完全取代 Transformer？

把整段历史压进一个**固定大小的状态**，必然有信息损失：

- **历史压缩**：有限精度的固定状态无法无界保留所有细节；关联回忆、重复 key、长 ID 抄写是值得专门测的压力场景。full attention 保留逐 token KV，也不保证一定检索正确。
- **更新规则**：核、门控、衰减和写入方式改变可表达的关系；不能简单说成「少一个 softmax 就少所有非线性」。

同参数量不等于公平预算。比较应控制训练 token、数据、活跃计算、上下文长度与推理成本，并报告不同任务表现，而不是宣称某家族一直略逊。

## 五、混合架构（当前主流答案）

既然各有所长，就**混着用**：大部分层用高效的线性/SSM 层（省、快、长），少数层穿插标准注意力（保留精确回忆能力）。

| 模型 | 做法 |
| --- | --- |
| **Jamba** | Mamba 层 + Transformer 注意力层 + MoE 交错堆叠 |
| **Mamba-2 与其混合实验** | Mamba-2 核心是选择性 SSM；混合注意力是可另行评测的配置，不是名称本身的定义 |
| 各家长上下文模型 | 滑动窗口注意力 + 少量全局注意力层 |

混合是工程取舍，不保证长、便宜且无质量损失。[Jamba](https://arxiv.org/abs/2403.19887)在特定配置上研究 Transformer、Mamba 与 MoE 的组合；少量全注意力层仍贡献随长度增长的 KV 和二次 prefill 算术量。

> 与滑动窗口注意力的关系：滑动窗口（每个 token 只看附近 W 个）也是把 $O(n^2)$ 降到 $O(nW)$ 的简单办法，常和少量全局注意力层组合（见 [长上下文专题](/basics/long-context)）。

## 高频追问

**Q：线性注意力为什么能做到 O(n)？**
改用可分解核后，以状态累计代替逐对物化；归一化版本还需累计分母。对固定核特征维和 value 维，序列长度上的成本为线性；不是标准 softmax 的直接等价变形。

**Q：线性注意力推理时为什么省显存？**
它把历史压缩进一个固定大小的状态（$d\times d$），不需要随序列增长的 KV Cache。无论上下文多长，状态大小不变——这正是它在长上下文推理上的最大优势。

**Q：既然线性注意力又快又省，为什么没取代 Transformer？**
固定状态引入压缩取舍，但任务差异、训练预算、状态维度和内核效率都会影响结果。应测关联回忆、冲突更新和长度增长曲线，而不是用一个榜单断言通用能力排序。

**Q：RWKV / RetNet 和 Mamba 是一回事吗？**
都属于「训练并行、推理递推、常数显存」的线性序列模型大家族，数学上高度相关（都可看作某种线性递推/状态空间）。区别在具体的状态更新规则、衰减/门控设计。Mamba 的卖点是「选择性」（状态更新依赖输入），见 [状态空间模型](/advanced/state-space-models)。

**Q：混合架构为什么是当前主流方向？**
它提供一种可调的效率/历史访问取舍，不是已经证明的最佳配置。要分别核算状态层与注意力层缓存，再测长程检索、吞吐和质量；本节旧标题中的「当前主流」不代表经过市场统计。

<summary>自测：归一化线性注意力里只有一个历史 token，输出应该是什么？</summary>

若核相似度非零，分子为该相似度乘 value，分母为同一相似度，结果正好是这个 value。遗漏分母则输出随相似度任意缩放；这是检查公式的最小反例。

**Q：滑动窗口注意力算线性注意力吗？**
不算同一类，但目标相同（降复杂度）。滑动窗口仍是 softmax 注意力，只是限制每个 token 只看邻近 W 个，复杂度降到 $O(nW)$；线性注意力是改变数学形式去掉 softmax。两者常与全局注意力层组合用于长上下文。
