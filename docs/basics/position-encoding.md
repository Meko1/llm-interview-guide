# 位置编码（Positional Encoding）

> Attention 本身对顺序无感知，必须显式注入位置信息。位置编码是长上下文相关面试题的核心，RoPE 更是现代大模型的标配。本文深入各方案的原理、优劣与长上下文扩展。长上下文系统梳理见 [长上下文专题](/basics/long-context)。

## 一、为什么需要位置编码？

不带位置项、全可见的自注意力是**置换等变（permutation-equivariant）**：设 P 为排列矩阵，$\mathrm{Attention}(PX)=P\mathrm{Attention}(X)$。这叫输出随输入排列变化，不叫输出不变；若再做对称池化，才可能得到排列不变的结果。因果 mask 本身也约束顺序，因此不能把上述结论无条件套到因果模型。

位置方案让模型明确区分位置与距离，而不是只从内容和可见性间接推断。

位置编码方案大体分两类：**绝对位置编码**（给每个位置一个表示）和**相对位置编码**（只关心两个 token 的相对距离）。

## 二、主要方案

### 1. 正弦绝对位置编码（Sinusoidal，原始 Transformer）

用不同频率的 sin/cos 函数为每个位置生成固定向量，加到词嵌入上：

$$PE_{(pos,2i)}=\sin\!\left(\frac{pos}{10000^{2i/d}}\right),\quad PE_{(pos,2i+1)}=\cos\!\left(\frac{pos}{10000^{2i/d}}\right)$$

不同维度用不同频率，组成多尺度位置特征。它不是二进制地址；周期性与有限精度也意味着不能据此承诺任意长位置都有可辨识的唯一编码。

- 优点：无需训练位置参数，可计算超出训练长度的位置，并具有可表达相对偏移的结构。
- 限制：能算出向量不等于模型能有效使用；外推质量要按训练长度和任务测。

### 2. 可学习绝对位置编码（Learned，BERT/早期 GPT）

把位置当作可学习的 Embedding（每个位置学一个向量）。简单有效，但**无法外推**——训练时没见过的位置（如第 5000 位）没有对应的、有意义的向量。

### 3. 旋转位置编码（RoPE，主流）★

RoPE（Rotary Position Embedding）是当前大模型（LLaMA、Qwen、GLM、DeepSeek 等）的主流方案。

**核心思想**：不给词向量「加」位置向量，而是**按位置把 Q、K 向量「旋转」一个角度**。把向量两两分组看作复平面上的点，位置 m 处旋转 mθ：

$$\langle R_mq,R_nk\rangle=q^TR_m^TR_nk=q^TR_{n-m}k$$

这里位置部分只通过相对差进入，但点积仍依赖 q、k 的内容；不能写成一个与内容无关的距离函数。旋转矩阵是多个二维块组成，两两配对的存储布局需与 checkpoint 一致，不一定就是相邻数组元素。

- 标准 RoPE 不额外学习位置参数，且便于修改位置映射或频率；但外推可靠性不是单独由 RoPE 保证。
- **base（频率基）**控制频率范围；10000 是常见历史设置，不是所有模型默认值。还需核对旋转维度、scaling 类型、位置 ID 与缓存处理。

### 4. ALiBi（Attention with Linear Biases）

因果 ALiBi 对每个头用一个距离斜率 $a_h$，向缩放分数加偏置：$s_{ij}=q_i^Tk_j/\sqrt{d_k}-a_h(i-j)$，其中 $j\le i$，未来仍由 causal mask 屏蔽。斜率和距离不能与 query/key 的内容匹配混为一谈。

- 优点：实现简洁；论文验证了指定训练/测试长度下的外推。偏向近邻也可能压低远处证据，不保证无界外推。
- 代表：BLOOM、MPT。

## 三、对比小结

| 方案 | 类型 | 可外推 | 增加参数 | 代表 |
| --- | --- | --- | --- | --- |
| 正弦 | 绝对 | 可计算新位置，质量需测 | 否 | 原始 Transformer |
| 可学习 | 绝对 | 固定表无新行；扩展需新策略与训练 | 是 | BERT |
| **RoPE** | 绝对旋转、相对点积 | 可扩展映射，质量需测 | 标准形式否 | 部分 LLaMA/Qwen/GLM 配置 |
| ALiBi | 相对偏置 | 可计算新距离，质量需测 | 标准斜率形式否 | BLOOM/MPT |

## 四、长上下文扩展（多基于 RoPE）

把一个 4K 上下文的模型扩展到 32K/128K，常见思路：

- **位置插值（PI, Position Interpolation）**：把超出范围的位置「压缩」回训练范围内（相当于缩小旋转角度），需少量微调。
- **NTK-aware Scaling**：调整频率基等参数，存在多种变体；需核对实际公式与长度设置，不能承诺免训练且无损。
- **YaRN**：处理不同频率区间并缩放注意力分数，在论文配置上结合继续训练验证扩展。其注意力尺度不是生成采样的 temperature，不能互相替换。
- **位置编码外的挑战**：扩展还要解决 KV Cache 显存、注意力 O(n²)、lost-in-the-middle，详见 [长上下文专题](/basics/long-context)。

## 五、高频追问

**Q：为什么 Attention 需要位置编码？** 全可见无位置自注意力置换等变，不显式表示位置和距离；位置方案补充这些结构。因果 mask 自带顺序约束，要区别于全可见假设。

**Q：RoPE 为什么能体现相对位置？** 对位置 m、n 的向量分别旋转 mθ、nθ 后做内积，结果只与角度差 (m−n)θ 有关，从而把相对位置编码进了注意力分数；同时旋转角度由绝对位置决定，兼具绝对与相对位置的优点。

**Q：RoPE 相比正弦/可学习编码好在哪？** 兼具绝对与相对位置、作用在注意力内部不增参数、外推性较好且便于插值扩展长上下文。这些综合优势让它成为现代大模型标配。

**Q：为什么可学习位置编码不能外推？** 它为每个绝对位置单独学一个向量，训练时没见过的位置没有对应的、有意义的向量，超出训练长度就失效。

**Q：怎么把短上下文模型扩展到长上下文？** 明确原训练长度、位置映射/频率修改、继续训练与服务配置，再分别测短窗口退化、长位置检索、干扰、缺证据与缓存一致性。改一个 base 不等于完成长度升级。

**Q：ALiBi 和 RoPE 的区别？** RoPE 通过旋转 Q/K 注入位置、改变向量；ALiBi 不动向量，直接给注意力分数加一个随距离增大的线性惩罚。ALiBi 更简单、外推更强，但 RoPE 表达更灵活、生态更主流。

**Q：长上下文的主要挑战是什么？** ① 位置编码外推；② KV Cache 显存随长度线性增长；③ 注意力 O(n²) 计算开销；④ 有效信息检索（lost in the middle）。位置编码只是其一，系统梳理见 [长上下文专题](/basics/long-context)。

<summary>自测：固定相对距离，RoPE 点积一定相同吗？</summary>

只在 q、k 内容也相同时成立。二维构造例子：相对旋转角为 0，q=k=[1,0] 时点积为 1；换成 q=[0,1]、k=[1,0] 则为 0。同样距离不代表同样注意力权重，因为还要与其他 key 一起 Softmax。

缓存排障时把「位置 ID」与「缓存槽位」分开：左 padding、滑窗驱逐或前缀复用后，槽位编号未必就是语义位置。用相同 token 比较一次完整前向与增量缓存前向的 logits；误差超出约定容差时先查旋转次数、位置偏移和 mask，不能立即归因于模型外推失败。
